# Learning — محتوای آموزشی CARACAL TUNING

این پوشه برای درس‌های دوزبانه و محتوای آموزشی عمومی خودرو است.

## دسته‌بندی پیشنهادی
- مبانی موتور و سیستم‌های خودرو
- آشنایی با ECU و حسگرها
- اصول عمومی دیاگ و خواندن کدهای خطا
- برق و الکترونیک خودرو
- نگهداری و ایمنی خودرو

## استاندارد هر درس
هر درس باید شناسه یکتا، عنوان فارسی و انگلیسی، سطح، متن، منابع، تاریخ بازبینی و وضعیت انتشار داشته باشد.

## انتشار
محتوا ابتدا با وضعیت پیش‌نویس ثبت می‌شود و فقط پس از بررسی منبع و بازبینی فنی می‌تواند منتشر شود. از انتشار دستورالعمل‌های پرخطر یا فایل‌های خام کالیبراسیون خودداری کنید.
