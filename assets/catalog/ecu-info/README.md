# ECU Information — راهنمای اطلاعات عمومی ECU

این پوشه برای شناسایی عمومی و آموزشی واحدهای کنترل الکترونیکی خودرو است.

## قالب پیشنهادی هر رکورد
- شناسه یکتا
- سازنده و خانواده ECU
- خودروها و بازه‌های سازگاری، فقط با منبع معتبر
- نشانه‌های شناسایی ظاهری و اطلاعات عمومی قابل انتشار
- منبع، تاریخ بررسی و سطح اطمینان
- توضیح فارسی و انگلیسی

## قواعد
- شماره قطعه یا سازگاری را حدس نزنید.
- اطلاعات هر خودرو را با چند تیپ یا سال دیگر یکی فرض نکنید.
- ثبت رکورد بدون منبع معتبر ممنوع است.
- این بخش شامل راهنمای شناسایی و دانش عمومی است، نه فایل خام، دامپ، کالیبراسیون یا دستور تغییر عملکرد ECU.
